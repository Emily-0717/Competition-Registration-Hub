```powershell
node tests/domain.test.cjs

node tests/startup.test.cjs
```

## 已知限制与未完成项

- 关闭应用后的系统定时通知未实现，运行期间约每分钟检查到期；提醒不能作为唯一截止保障。
- 文件拖拽、多业务窗口、内容差异对比、文档规则解析和自定义导出命名规则编辑器未实现。导出使用固定安全命名规则，并由系统另存选择器选择 ZIP 路径。
- 文件关联建立于材料导入，当前没有独立的跨材料重新关联向导。可在另一材料重新导入建立独立副本。
- 资格证明通过材料 ID 关联，缺少可视化选择器；团队成员信息使用专业 / 年级与备注字段，未做完整人员档案。
- 月历按日期展示任务，尚未完成星期布局细节、跨月拖动和系统日历同步；竞赛分组通过顶部竞赛 / 赛道范围选择实现。
- 主题可切换，但偏好当前不跨重启保存；重启跟随系统。
- 临时恢复目录与孤立托管文件采用保守保留策略，尚无空间清理界面。备份恢复限制 2 GB、10000 条目且不支持 ZIP64。
- 数据库采用公共索引列加 JSON payload，部分关联由业务层保护；未完成长期大数据量、多窗口并发或跨进程写入验收。
- 备份恢复和完整 UI 未经真机端到端验证，不应将本交付描述为完整生产验收版本。模拟器启动闪退已修复并验证，其他用例按上表状态判定。
