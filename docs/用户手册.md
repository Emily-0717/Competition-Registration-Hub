# 用户手册

## 一次完整报名流程

1. **我的竞赛 → 新建**：填写名称、主办方、级别、类别、报名起止、官方来源与网址。保存后在顶部选中竞赛。
2. **赛道管理 → 新建**：填写赛道名、作品截止时间和要求。保存会生成七项材料模板。模板不是对某赛事真实规则的自动判断。
3. **报名资格 → 新建**：逐条录入年级、专业、团队人数、导师、原创性等要求；填写来源；人工选择待确认、符合或不符合。证明材料应先在材料清单中创建，将其 ID 填入规则证明字段。
4. **材料清单**：按官方要求编辑每项材料的必填性、允许格式、大小、负责人、截止时间和备注。可补充自定义材料，也可删除尚无历史的无关模板。
5. 点击材料 **详情 → 导入文件 / 新建版本**。系统文件选择器只访问你选择的文件。导入后材料的当前版自动指向新版本，但不会替换已指定的最终版。
6. 在版本历史编辑版本名称、修改人、说明和审核状态。材料详情可切换当前版、查看不同版本元信息、指定最终版。恢复只改变指针。
7. 审核内容完成后，将材料状态改为 **已完成**。指定最终版本不会自动将整项材料标为审核完成。
8. **提交核验 → 执行核验**。修复未通过项；对资格、签章、原创性和真实文件格式进行人工确认。
9. **导出最终材料 ZIP**：再次核验，阅读并确认人工事项，选择保存位置。ZIP 含材料最终版、提交清单和报告；原始文件不变。

## 资料库与版本

- 文件资料库支持列表和网格。按顶部赛道查看对应材料文件；搜索名称、负责人和备注。
- 文件详情提供存在性与 SHA-256 检查、导出、图片 / PDF 预览或系统打开。
- DOCX / PPTX 需要设备上安装能够处理该格式的应用。无法打开时界面显示系统错误，不会生成假的文档页面。
- 文件展示名称可编辑，扩展名不能更改；物理文件以独立 ID 保存在私有目录。
- 历史版本与托管文件不可直接删除。若竞赛已结束，优先归档竞赛，保留追溯信息。
- 当前版本用于继续准备；最终版本用于导出，两者可以不同。

## 团队、任务与提醒

竞赛详情可添加 / 编辑 / 删除团队成员。创建任务时默认关联当前竞赛，设置优先级、负责人、截止时间及备注。月历显示当前竞赛任务的日期。完成任务后将状态设为已完成。

任务详情可设置截止提醒；提醒保存后可修改时间或取消。授权系统通知后，应用运行期间约每分钟检查到期事项。关闭应用后不会主动唤醒；重新启动后继续检查。未授权通知时提醒数据仍可保留，但系统通知可能失败，请查看状态栏。

## 备份与恢复

设置中选择完整备份，导出包含数据库及全部托管文件的 ZIP。备份含个人材料和成员信息，建议保存于受保护的位置。

恢复前先备份当前资料。选择本应用生成的完整备份；恢复会替换数据库并重新定位文件路径，保留旧托管文件。损坏、未知结构、路径穿越、哈希不符或同 ID 不同内容的备份会被拒绝。当前不支持 ZIP64 或超过 2 GB 的恢复包。

数据库和文件恢复仍需真机端到端验收。重要资料应保留独立原件及多个备份，勿只依赖单一应用副本。

## 界面与反馈

设置中切换系统 / 浅色 / 深色主题。宽窗口使用右侧详情面板；窄窗口进入详情页后点击返回列表。主要数据可搜索、按最近或名称排序，状态可筛选。

Ctrl+N：在支持创建的页面新建；Ctrl+F：搜索；Esc：关闭编辑或预览。状态栏显示加载、成功、取消及错误。文件拖拽、多窗口、内容差异对比未启用。

## 常见问题

- **不能删除竞赛 / 赛道**：存在关联子项。请先处理关联记录，或使用归档。
- **已上传文件仍未通过**：检查必填材料审核状态、最终版、格式、大小和资格条件。
- **自动核验通过但报告有警告**：机器不能判断签章或真实性，必须人工复核。
- **恢复被拒绝**：请使用本应用完整备份；查看错误提示，不要手工改 ZIP 内容尝试绕过检查。
- **保存失败**：查看状态栏，确认可用空间、权限和 SDK 兼容性。失败操作不得当作已提交成功。
