# 软件架构与数据库

## 分层

`Index` 只协调页面状态和服务调用；`Domain` 中核验与准备度不依赖平台；`Repository` 负责 RDB 和事务；`FileService` 负责 URI 授权后文件 IO、哈希与 ZIP；`EntryAbility` 加载原生页面。核心数据不依赖网络。

## 数据表

11 张表均有 `id TEXT PRIMARY KEY`、`parent TEXT NOT NULL`、`name TEXT NOT NULL`、`at INTEGER NOT NULL`、`payload TEXT NOT NULL`，每张表有 parent 索引。payload 存储完整显式 Item 字段，满足当前迭代和原子保存；索引列维护与 payload 一致。版本 1 无历史版本迁移需求；以后扩展必须新增迁移而非覆盖数据库。

|表|parent 关系|关键 payload 字段|
|---|---|---|
|Competition|根|主办方、类别、级别、报名起止、官方通知、入口、状态|
|Track|Competition，RESTRICT|独立截止、要求、备注|
|EligibilityRule|Track，RESTRICT|符合 / 不符合 / 待确认、来源、证明材料 ID、备注|
|MaterialRequirement|Track，RESTRICT|必填、格式、大小、负责人、截止、审核状态、current / final|
|MaterialFile|MaterialRequirement，RESTRICT|文件名、私有路径、字节、mtime、SHA-256|
|FileVersion|MaterialRequirement，RESTRICT|版本名、关联文件 ID、修改人、备注、审核状态、时间|
|TeamMember|Competition，RESTRICT|成员名、专业 / 年级及备注|
|Task|竞赛 / 赛道 / 材料，多态父关联|优先级、负责人、截止、完成状态|
|Reminder|Task，RESTRICT|提醒时间、已发送标志|
|VerificationResult|Track，RESTRICT|执行时间、结果、完整文本报告|
|OperationLog|根|动作、目标 ID、时间|

文件版本的 source、材料 current / final、资格证明 current、任务的多态 parent 在服务层验证。它们目前不使用额外 SQL 外键；绕开 Repository 直接修改数据库会破坏约束，不属于支持的操作。显示名称允许重复，实体 ID 唯一。表名由静态白名单限定；业务字段通过 ValuesBucket 和 Predicates 绑定。

## 数据一致性

- 新增 / 更新和对应操作日志处于同一 RDB 事务，失败回滚。
- 更新用 UPDATE 后 INSERT，不用 REPLACE，避免外键父记录被隐式删除。
- 有子项、资格证明引用或历史版本的对象无法直接删除。文件和版本禁止删除；归档用于保留竞赛全链路。
- 导入先复制并计算哈希，再在一次数据库事务内写入文件 / 版本 / 当前指针。数据库失败则清理新副本。崩溃窗口可能留下没有元数据的托管文件，当前保守保留而不自动删除。
- 恢复历史只更新当前版本指针，不覆盖原始文件；最终指针独立。
- 导出再次验证最终文件 SHA-256，复制到临时目录后调用正式 ZIP API，通过系统另存选择器写出。
- 备份使用 RDB `backup` 生成一致数据库快照，复制全部私有材料后打包。恢复先限制 ZIP 路径、类型、大小与条目数量；校验各材料哈希；ID 冲突不覆盖。数据库恢复失败时尝试回滚到恢复前快照。

文件与 RDB 不具备跨系统事务。恢复过程中崩溃、磁盘空间不足或回滚也失败时，需要重新从完整备份恢复。恢复追加的未引用文件会保留，避免误删原资料。恢复期间临时目录尚未提供自动清理界面。

## 核验语义

“通过”仅表示当前已配置且机器可判断的要求得到满足。人工确认警告可与自动通过并存，报告总状态仍为警告。缺少材料规则、必填未审核、最终文件缺失 / 损坏、大小 / 扩展名不符和明确不符合资格均阻止导出。

扩展名核验不验证二进制真实格式。应用不改扩展名来转换格式，也不会认定签章、真实性和原创性已经自动核实。

准备度 = 必填材料有版本 × 40% + 必填审核完成 × 25% + 资格符合 × 20% + 必填最终版指定 × 15%。规则缺失计零；不符合资格上限 49；三日内截止且未全完成上限 69；赛道逾期计零。准备度不代替最终核验。

## 当前规模限制

当前以全量载入数据后筛选为主，适合个人 / 小团队本地资料库。尚未完成万级材料、超大文件、低磁盘空间和长期操作日志增长的性能验收。备份恢复拒绝 ZIP64，限制 2 GB 解压量、10000 条目与 4 MB 中央目录。托管文件不自动删除，用户需要预留空间。
