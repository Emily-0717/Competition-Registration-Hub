# 模拟器启动闪退修复

日期：2026-10-15。环境：用户正在运行的 MateBook Pro 模拟器，HarmonyOS 6.0.2 / API 22。

## 已确认原因

从模拟器 `/data/log/faultlog/faultlogger` 取得的实际崩溃日志：

```text
Reason:SyntaxError
the requested module '@hms:officeservice.PdfView' does not provide an export name
'pdfViewManager' which imported by '&entry/src/main/ets/pages/Index&'
```

正式 SDK 存在该接口、ArkTS 编译通过，并不意味着模拟器镜像提供同样的运行时导出。此前首页静态导入 PDFKit 并在构造时初始化控制器，使可选预览能力缺失变成整个应用启动失败。

## 修改

- 首页静态依赖中移除 PDFKit 与 PDF 控制器构造。
- 增加独立 `pages/PdfPreview` 页面。仅在用户打开 PDF 且运行时检测通过后进入。
- 先检查系统能力，再通过可捕获的动态导入确认 `PdfController`、`PdfView` 实际存在；缺失或异常时使用系统应用打开 PDF。
- PDF 文件或控制器加载失败在预览页面显示错误。
- 同时补齐窗口限制的最大宽高，消除模拟器原先记录的参数转换警告。

## 实际验证

1. API 22 再次编译、HAP 打包及 PackingCheck 成功。
2. 使用 hdc 在用户现有模拟器上覆盖安装，未卸载应用、未清空沙箱资料。
3. 第一次启动成功，首页真实显示，状态栏为“资料已安全保存在本机”。
4. 强制停止后再次冷启动成功，进程正常存活。故障目录没有出现新的 CompetitionHub 崩溃记录。
5. 新增 5 项回归测试：系统能力缺失、命名导出缺失、模块加载异常、完整能力及首页静态依赖图检查。总计 46 项主机测试通过。
